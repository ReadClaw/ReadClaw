> 超级货运的出口通道：真空的月球表面，高速列车完全不必采用真空隧道的方式即可悬浮运行，极为适合大规模的货物运输，例如矿物与月球产品。人类乘坐超级加速的列车生理无法承受，但货物可耐受。由高速行驶的货柜抵达巡月平台转送出，或者货列直接穿梭于地月轨道，把月球出产的物资运往地球。因此，绵湖入口与货列出口形成地月交换的良好循环。

> <mark>“充气宝”储能思路：</mark>月球储能模式前景最被看好的并非电储能而是高气压储存，因为月球的气压差，转换效率可达95%以上。已探明月球具有广泛的天然隧洞，这样的地质结构极其适合用于存贮高压气体。电解月壤产生氧气与水，多余的副产气可以被泵入地底熔洞内进行储藏。这些高压气不仅适合用于物质抛运、舰舱发射以及货列的弹射，还可以高效用于生产发电或者供应临近的工厂让设备运转。反复猛烈的气体释放还必然吹尽泄出口邻近区的月壤，暴露出月岩表面，形成大片干净无尘的区域，非常适合人类建设居住场所。采用大片的玻璃幕能近距离观赏到物体被抛射的壮观场面，会成为月球的景观地点。而朝向绵湖上空以定点方式排出的气体还可以形成短暂气层减速带，让重质量货物附加伞降方式安全溅落至绵湖。有理由相信，月球绵湖区与充气宝地带将构成繁忙的产业带，形成月球亮点，带动月球经济快速发展。

> 高速出行的解决：理论上，月球高铁可以在交变电磁场控制下被加速，实现浮离于地面行驶，当速度到达脱离速度时，无需轨道以惯性动力即可在月表真空中穿行，一次性把群体送至远距离站点，从一个月海到另一个月海。这意味着质量更小的汽车也能轻易被加速，以更短的加速通道被弹射跃行于月空中。在运算的调度下，这种中远程出行方式会秩序井然且安全，让两点间的直线距离成为真实捷径。同时开源开发者可以设计多个中转区，不需要太多的出行成本（时间与金钱）就能满足月球上众多个体的多方位点对点出行，身处跃行星球的体验在地球上是完全不可想象的。

> 局部能供的解决，罩射法：月球陨石坑譬如绵湖区的能量维持可采用<mark>从上向下的电磁波罩射方式供给</mark>，悬停于绵湖上方的电梯舱需要动力才能长期维持，除了搜集太阳能之外核动力也可以考虑。个人认为，人类的第一个小型核电装置不一定非得建造在地面，可以安装在巡月舱上，像母舰航空一样从上方为月面的工作区提供能源，下方以换能器接收，转化为电能，同时提供中继覆盖网络。更可以巧妙设计定点反射，控制大型镜面角度方位，把日光汇集到具有透明穹窿的居民区，形成局部温升。另外，大型高亮灯聚合形成“小太阳”，持续照耀永冻陨坑用于蒸发水冰也是种好方法，该能量可以取用飞船本身运行的辐射散热或额外补充给的动力。由于绵湖区并未有气体来维持温度，故而应当采用深色的高密度人造海绵来充填陨坑，且该物质需具有良好的导热、容热性能，或者还可以采用坑基气膜沿着月坑周脊布设，形成封闭坑凹的方式来解决。

> 寻找适合的天然月坑建造巨型射电望远镜：当看到中国贵州的“天眼”射电望远镜时，人们感慨500米直径的FAST，因此提出在月球表面大大小小月坑中找到适合的去建立“月球眼”的可能性。在低重力环境下，望远镜可以建造得幅面更大，月球干扰小且环境更安静，若能组建多个阵列群（包括在月背面），则不可想象将获知多少天文天象！一旦完成从传感器至大型机械的开源任务，本人认为第一个该建造的就是这样一个大型科学仪器。

> 以地月为半径的EHT（事件视界望远镜）：黑洞摄影技术仰赖EHT“巨瞳”，如果地月间的多个望远镜以VLBI执行等效任务，结合引力波、中微子侦察，深维度等构成多信使的天文时代，真的可以<mark>解决宇宙起源之谜</mark>。

> 利用好经纬天平动，做人类新的娱乐带：给月球镶上金边的唯一办法就是在天秤区建立娱乐城。在地球上，人类可以填海打造豪华地标，在沙漠中筑成日不落城市，而地球人凭肉眼可以看见的销金库就在月球的天秤区。该地区又是月球唯一能实现看到半个地球甚至地升地落的地带，如果说月球上有什么甚佳的风景点，这里就是！开源设计家可以在这里尽情施展才华，让高耸的建筑几乎碰触地球，让人坐乘透明电梯看着地球变动。而用于抵抗月震的宽阔基底内则深藏着大型城市，一旦黄金合约达成，来旅游的人们将络绎不绝。这里会有号称太阳系最大摩天轮的儿童乐园，超级恐怖的连续跨越多个月坑、接续数个起伏山峦的月球过山车，以及开辟从月迎面至月背面的环月观光列车。

 ❗ 注意前置化：由于月球物质匮乏，所述的传感器、计算设备、探索与建设机械都建议用地球上富余，而月球匮乏的物质制造。例如，地球上铁镍元素丰富，而月球的丰度极低，我们<mark>应当毫不吝啬地把这类亲铁物质以吨计地投向月球</mark>，一旦时代进展，这些淘汰的月球垃圾依然是极其珍贵的物质原料（因器件在发射前已被共识，回收时能经溯源把价值归至原主）。
